# PVIntell is global

PVIntell is a global application. This is a permanent product requirement for every ChatGPT/Codex task in this repository.

- Approach every feature, explanation, glossary entry, guide, component, calculation, recommendation and AI instruction from a global perspective.
- Never use New Zealand—or the developer's, machine's, timezone's, test fixture's or current account's location—as the silent product default.
- Apply country-, state/province-, network/utility- or standards-specific information only when the user explicitly provides that jurisdiction or the relevant Site has a confirmed location.
- When location materially affects an answer and is unknown, use internationally neutral language, identify what varies, and request the country/region rather than selecting one.
- Where a global explanation benefits from examples, cover relevant major regional patterns and label every regional example. Do not present any one region's voltage, terminology, metering, ownership boundary, tariffs, products, standards, licensing or legal rules as universal.
- Regional overlays are allowed and useful, but they must sit on top of global base knowledge and be selected from confirmed Site context.
- For any system-specific work, the system's confirmed Site/pin location is the controlling jurisdiction. It overrides the user's account, home, device, login, server and developer locations. A user in one country may design or operate a system in another.
- Account or device location may be offered as a convenient Site-location suggestion because it will often match, but it must remain an unconfirmed suggestion until the user accepts or pins the system location. Matching values do not remove this distinction.
- A request to add, change or replace an image/icon means replace that visual globally across every applicable PVIntell surface—including schematic, component library, Glossary, How-to, discovery, overview and design views—unless the user explicitly limits the request. Use one canonical asset reference and remove superseded assets so stale versions cannot reappear.
